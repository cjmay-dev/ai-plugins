# Changelog

All notable changes to the compose-template plugin will be documented in this file.

## [1.0.0] - 2024-02-11

### Added
- Initial release of compose-template Claude Code plugin
- Five comprehensive skills for compose-template workflows:
  - `compose-init`: Initialize new applications from template
  - `compose-local`: Set up local development environment
  - `compose-infra`: Deploy and manage Terraform infrastructure
  - `compose-deploy`: Deploy Docker Compose applications
  - `compose-backup`: Configure stack-back backup system
- Specialized `compose-template-expert` agent with deep compose-template knowledge
- Complete documentation:
  - Plugin README with overview and features
  - INSTALL.md with installation instructions
  - USAGE.md with comprehensive examples and workflows
- Marketplace configuration for plugin discovery
- Plugin manifest with metadata and configuration

### Plugin Features
- Automatic skill invocation by Claude when appropriate
- Context-aware agent that understands compose-template architecture
- Comprehensive guides for:
  - Docker Compose application deployment
  - Terraform infrastructure management
  - Infisical secret management
  - stack-back backup configuration
  - Traefik routing configuration
  - Local development workflows

### Documentation
- ~2,000 lines of comprehensive documentation
- Real-world examples and troubleshooting guides
- Best practices and security considerations
- Step-by-step workflows for common tasks
